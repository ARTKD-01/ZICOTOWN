กฎทํางานดํา

  1. In Character (IC) — พูดและกระทำตามบทบาทตัวละครภายในเกม โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  2. Out Of Character (OOC) — เรื่องราวนอกบทบาทต้องไม่ถูกนำมาปะปนกับการเล่นในเมือง โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  3. Breaking Roleplay (BK) — ห้ามเล่นขัดกับสถานการณ์หรือจงใจทำให้ผู้อื่นเล่นต่อไม่ได้ เช่น ออกจากเกมเพื่อหนีสถานการณ์ โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  4. Power Gaming (PG) — ห้ามแสดงความสามารถเหนือมนุษย์หรือทำสิ่งที่คนทั่วไปทำไม่ได้ในชีวิตจริง โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  5. Meta Gaming (MG) — ห้ามนำข้อมูลจากนอกเกมมาใช้ให้ตัวละครได้เปรียบในเกม โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  6. Revenge Kill (RK) — เมื่อตายหรือสลบ ห้ามจำเหตุการณ์ช่วงนั้นเพื่อนำไปแก้แค้นหรือสร้างสตอรี่ต่อ โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  7. Deathmatch (DM) — ห้ามทำร้ายหรือฆ่าผู้อื่นโดยไม่มีบทบาทหรือเหตุผลของสตอรี่ โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  8. Spawn Kill (SK) — ห้ามดักทำร้ายผู้เล่นที่เพิ่งเข้าเกม เพิ่งเกิด หรือยังควบคุมตัวละครไม่ได้ โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  9. Face Off Character (FOC) — ห้ามสวมบทบาทแทนผู้อื่นหรือเล่นหลายบทบาทเพื่อหลบผลลงโทษของตัวละครเดิม โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  10. Toxic / Sexual Harassment / Bully — ห้ามคุกคาม เหยียด ด่าทอรุนแรง ล้อเลียนทางเพศ หรือก่อกวนผู้อื่นซ้ำ ๆ โดยเจตนา โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)
  11. Protect Yourself — ควรบันทึก Overlay หรือหลักฐานการเล่นไว้เพื่อใช้แจ้งหรือปกป้องตัวเอง โทษ : ปรับ 100k - 300k / ใบเหลือง / ใบส้ม / ใบแดง หรือทั้งใบทั้งปรับ (ตามดุลพินิจทีมงาน)

การฝ่าฝืนกฎอาจมีโทษปรับ 100,000–1,000,000 บาทในเกม หรือได้รับใบเหลือง ใบส้ม ใบแดง และอาจได้รับทั้งโทษปรับและใบ ขึ้นอยู่กับความรุนแรงและดุลพินิจของทีมงาน
